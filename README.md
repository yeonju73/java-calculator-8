# java-calculator-precourse

## 구현할 기능 목록

### 0. 입출력 기능

- 사용자로부터 덧셈할 문자열을 입력받는다.
- 계산 결과를 형식에 맞게 출력한다.

### 1. 기본 구분자 처리 기능

- 빈 문자열을 입력할 경우 0을 반환한다.
- 숫자 하나만 입력할 경우 해당 숫자를 반환한다.
- 쉼표(,) 또는 콜론(:)을 구분자로 사용하여 각 숫자의 합을 구한다.

### 2. 커스텀 구분자 처리 기능

- //와 \n 사이의 문자를 커스텀 구분자로 사용하여 각 숫자의 합을 구한다.

### 3. 예외 처리 기능

- 음수를 입력할 경우 IllegalArgumentException을 발생시킨다.
- null 또는 형식에 맞지 않은 문자열을 입력할 경우 IllegalArgumentException을 발생시킨다.
